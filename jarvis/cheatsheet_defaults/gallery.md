# Gallery — Quick Reference

**Gallery Home** (`Ctrl+Shift+G`) is Aria’s local AI image product.

## Boundaries

| Gallery | Others |
|---------|--------|
| Generate / browse / edit stills | Video = motion |
| Prompt history & search | Meme = captions |
| Optional Vision metadata | Documents = knowledge |
| Soft delete / collections | Chat = conversation |

## Chat / Gallery

Prefer generating **in Gallery**. Chat can still run `generate image: …` — jobs are shared.

| You say / do | ARIA does |
|--------------|-----------|
| Gallery → Generate | Queues job, stays in Gallery, refreshes grid |
| Search “red car” | Filename + prompt + optional captions |
| Trash image | Soft delete with Undo |
| Select → Video storyboard | Suggests order — create clip in Video Studio |

## Safety

- Restricted stills from uncensored mode show placeholders in censored profile  
- Metadata Vision is **opt-in** per image  
- Destructive voice commands require confirmation
